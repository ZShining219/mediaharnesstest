# 裂变素材（个体带货）功能说明

> 面向：运营/编导/客户成功/试用用户
> 当前版本：商品/人物配置 + 视频池无感对标 + 批量契约/生成
> 一句话：**把你的商品图和人物图交进来，系统参考整个视频池的结构与信息，生成多条 12 秒抖音个体带货视频。**

## 1. 它解决什么问题

之前的裂变素材看起来像“品牌产品说明片”：

- 纯白台面、固定机位、只有手部；
- 没有真人、没有口播、没有字幕；
- 只讲商品结构，不讲痛点、证明、场景、价格；
- 画面干净，但信息密度低，不像抖音个体带货。

现在换成“个体带货”范式：

- 真人居家出镜，直接对镜头说话；
- 有口播、有硬字幕；
- 12 秒里放 4 个卖点、4 个证明、多色/穿搭、价格 CTA；
- 商品还是你的商品，人物还是你指定的人物。

**关键：不是把参考视频换脸/换商品，而是把参考拆成“怎么拍、讲什么、怎么证明、怎么收口”，再用你的素材重拍。**

## 2. 用户视角：4 步（网页：工作台 → 裂变素材）

### 第 1 步：选商品

选择已配置的商品 Profile（例如 `bra-milk-lace`），或直接上传商品图。

系统会自动带出这个商品的：

- 不可变特征（颜色、材质、版型、必须出现的细节）；
- 真实卖点、证明方式、价格/活动信息；
- 哪些颜色/款式属于同款多色，哪些不能出现。

> 商品图只负责商品本身；图里的手、背景、文字不会被带进成片。
> **用户不需要选对标视频**：后台会把整个视频池作为整体参考，归纳开场、证明、信息密度和收尾。
> 当前网页只能选择已配置的 Profile；新增商品需要先在 `configs/products/` 加一份 Profile（后续会做网页配置）。

### 第 2 步：确认商品事实

在商品描述里补充或修正：

- 颜色、材质、版型、必须出现的细节；
- 真实卖点、真实价格/活动信息；
- 哪些颜色/款式属于同款多色，哪些不能出现。

当前商品事实来自 `configs/products/*.json`；网页上选 Profile 即可复用，改文字只影响本次 brief。

### 第 3 步：选人物

上传有授权的人物图，系统只复用：

- 脸型、发型、体型、肤色；
- 服装/场景由契约替换（例如米色针织开衫、居家客厅）。

> 人物图是独立资产，不是从参考视频里抽的；没有授权不要用真人图。
> 当前商品 Profile 里已绑定测试人物图，正式使用前必须确认肖像授权。

### 第 4 步：生成与验收

设置数量（1–10 条），点“生成裂变素材”。系统会先产出多个不同结构的契约，再逐条生成 12 秒、9:16 竖屏视频，包含：

- 真人画面 + 商品特写 + 居家场景；
- H3 原生中文口播、环境音、BGM/音效；
- 后期硬字幕；
- 商品校验（identity/color/detail）。

页面会显示 7 个阶段（参考池 / 商品 Brief / 全池指导 / 变体规划 / 契约 / 生成 / 评估）；每条变体可查看 Prompt、契约、下载，并进入审核队列。生成中断可点“继续生成”，已完成的视频不会重复扣 H3。

同一批不会全是“真人手持口播”。系统会先从视频池归纳出若干条**呈现车道**，再把变体锁定到不同车道，例如：

| 车道 | 人物 | 声音 | 典型画面 |
|---|---|---|---|
| 正面口播 | 真人正脸 | 同期声口播 | 半身对镜头讲痛点/卖点 |
| 侧身/背影 | 真人侧后方 | 画外女声 | 转身展示肩带、背面四排扣 |
| 纯手部字幕卡 | 只有手 | 无口播，BGM/音效 | 桌面俯拍翻转、按压、捏拉 |
| 桌面静物 | 无人物、无手 | 环境音 | 平铺、翻面、微距陈列 |

页面会给每条变体打上车道、人物呈现、声音呈现标签，并在阶段栏显示“多元车道 N/N”。

验收看 5 件事：

1. **前 1–2 秒**：真人/痛点/商品是否出现；
2. **信息密度**：是否有 4+ 卖点、3+ 证明、4+ 字幕/口播、2+ 场景、1 个 CTA；
3. **商品**：是否变形/变色；多色是否符合策略；
4. **人物**：是否一致；授权是否 OK；
5. **合规**：功效词、价格、暴露尺度是否可接受。

## 3. 它和旧版有什么区别

| 维度 | 旧版（产品说明片） | 新版（个体带货） |
|---|---|---|
| 人物 | 仅手部 | 真人出镜口播 |
| 场景 | 纯白台面 | 居家客厅/卧室/桌面 |
| 信息 | 只讲结构 | 痛点、卖点、证明、多色、CTA |
| 声音 | 无声/丢弃原生音轨 | H3 原生口播 + BGM/音效 |
| 字幕 | 无 | 大字硬字幕 |
| 观感 | 品牌宣传片/目录 | 抖音个体带货/种草 |
| 参考选择 | 人工选 1 条 | 用户无感，整个视频池参与归纳 |
| 参考使用 | 只借商品图 | 借结构、信息、证明、节奏 |
| 溯源 | 无 | 每个 beat 标明用了哪条参考的哪个镜头 |

## 4. 它不是什么

- **不是视频洗稿/换脸/换商品**：参考视频不会直接喂给生成模型；只提交人物图和商品图。
- **不是固定套某个对标模板**：视频池只提供整体规律（结构、信息密度、证明方式），每次由 LLM 重新组合成多个不同变体，不锁定某一条参考。
- **不是让模型随便编卖点**：卖点/价格/功效必须来自真实信息；当前 CTA“活动价”只是占位，正式使用要填真实活动。
- **不是一键发布**：生成后仍需人工审核商品、人物、价格、平台合规。
- **不是 100% 复刻参考**：复用的是范式和信息结构，不是逐帧画面。

## 5. 对外话术

### 30 秒版

> 你把商品图和人物图交进来，选一个商品配置、填数量。系统会把整个视频池的开头、卖点、证明和收尾归纳成“拍摄配方”，生成多条 12 秒竖屏带货视频，有真人出镜、口播、字幕和 BGM。你不用选对标视频；它不是把参考视频换脸，而是用参考的结构重拍你的商品。

### 3 分钟版

> 过去我们做裂变，容易做成“品牌产品说明片”：干净、安静、只有手和产品，信息很少。  
> 现在换成“个体带货”范式：你选商品配置、确认商品事实、选一个授权人物图；系统在后台把整个视频池归纳成痛点、卖点、证明、场景和 CTA，自动规划多个不同结构，再逐条生成 12 秒竖屏视频。  
> 生成时，画面、中文口播、环境音和 BGM 是一次生成的，口型同步；字幕后期烧上去。  
> 生成后我们看五件事：前 2 秒有没有抓人、信息密度够不够、商品有没有变形、人物有没有授权、价格/功效/暴露尺度是否合规。  
> 它适合个体带货和模特种草，不适合纯品牌 TVC；参考视频不会被洗稿，卖点也不能乱编。

## 6. FAQ

**Q：为什么看起来像抖音个体带货，不像广告片？**  
A：因为换了范式：真人、居家、口播、大字幕、痛点/证明/CTA，而不是纯白台面+固定机位。

**Q：参考视频会被“洗”吗？**  
A：不会。参考视频只用于拆结构和信息；生成时只提交人物图和商品图，不提交参考视频。

**Q：人物是谁？能换吗？**  
A：人物是你上传的固定人物图，必须有授权；可以换人物，但要重新确认人物特征和服装/场景。

**Q：卖点和价格会乱写吗？**  
A：不会自动编。契约里每个卖点/价格都要有来源；正式使用前要填真实活动信息并人工审核。

**Q：为什么还要人工审核？**  
A：商品是否变形、人物是否一致、价格/功效是否真实、暴露尺度是否合规，目前都需要人看一眼。

**Q：能批量吗？**  
A：可以。网页上一次选商品/人物、填数量，系统会批量产出契约并逐条生成；当前是顺序生成，批量前仍需确认多色策略、试穿尺度、原生音频和合规规则。

**Q：为什么有时候字幕和口播不完全一致？**  
A：口播由 H3 原生生成，字幕是后期按脚本烧的；当前脚本和口播是对齐的，但如果改台词，要同步改字幕和口播文本。
