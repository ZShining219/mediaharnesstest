## 4. 本切片的问题

1. **TTS 已降为后备**：H3 原生音频验证可用，`variant_ugc_native.mp4` 保留原生音轨。MiniMax 官方 TTS 余额不足（status_code 1008），只在 `--no-native-audio` 时作为后备；本机 `say` 是最后的兜底。
2. **多色画面与“商品颜色不可变”冲突**：第 5 帧出现黑/灰色文胸，契约里 `must_not_change` 写的是奶白/米白。需要明确：
   - 如果同款有多色，允许“同款多色”，把约束改为“同一款式/材质，颜色属于同款色系”；
   - 如果必须严格单色，删掉多色平铺，改成同色不同角度/包装。
3. **真人试穿镜头偏露**：第 4 帧是白衬衫敞开 + 文胸，属于内衣广告常见尺度，但部分平台可能敏感。可改为“针织开衫只露肩带/领口”，或保留但走人工审核。
4. **第 4 个切点 9.08s，晚于计划的 8.5s**：CTA 只剩 2.9s，略紧；可把 beat 3 缩短到 2.5s，给 CTA 3.5s。
5. **无 BGM**：`assets/bgm/` 为空，当前只有口播。加一条轻量 BGM/音效会明显提升“个体带货”的能量感。

## 5. 结论

- 这次切片证明：**换范式 + 补信息层**就能从“品牌产品说明片”变成“真人居家种草”，不需要靠提高帧间运动。
- 商品校验仍能 9/9/9 通过，说明真人/场景/字幕不会破坏商品身份。
- 下一步应该把 `format_archetype` 和 `information` 槽位固化到 facet/contract v1，并把 UGC 作为默认带货范式；`product_demo` 保留为单独的“静物演示”预设。
- 在批量前，先决定两件事：多色是否允许、真人试穿尺度；再决定 TTS 是否充值 MiniMax 或继续用本机音。

## 6. 复现

```bash
.venv/bin/python scripts/fission_ugc_slice.py

# 2) 生成 + 保留 H3 原生音频 + 硬字幕（默认路径）
.venv/bin/python scripts/run_contract.py \
  --contract data/fission_slices/slice-1471-ugc-direction1/contract.json \
  --prompt data/fission_slices/slice-1471-ugc-direction1/prompt_h3.txt \
  --out data/fission_slices/slice-1471-ugc-direction1 \
  --name variant_ugc_native.mp4

# 如需强制走 TTS（原生音频不满意时）
.venv/bin/python scripts/run_contract.py ... --no-native-audio
```
