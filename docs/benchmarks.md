# 对标产品调研

> 2026-09-30。目的：为"视频转换（换人/换衣/换背景）"和"数字人"两条功能线找产品形态参照。

## 一、对标视频转换类

### Viggle AI（viggle.ai）—— 换人赛道的标杆
- **核心卖点**：一张人物图 + 一段视频 → 整人替换（脸+身体+衣服+比例全换），保留原动作/场景/镜头
- 自研 JST-1 "视频-3D" 基础模型：物理感知（重力/动量/肢体力学），快速舞蹈/武术不崩坏
- 产品形态极简：**选模板视频（8000+动作库）→ 传一张图 → 一分钟出片**
- 还有：Motion Control（视频→3D 骨骼动画）、多人同屏替换（Multi-Track 逐人换）
- **对我们的启发**：用户只要"图+视频→出片"，参数藏到背后 —— 我们工作台的"对标视频转换"卡片/画布节点即此形态；底层用开源 Wan2.2-Animate（replace 模式同思路：整人替换保动作）

### DomoAI（domoai.app）
- Character to Video：替换角色保留动作；**"Subject Only" 开关 = 只换人保留背景**
- Video-to-Video 风格迁移：40+ 预设画风（动漫/水彩/油画），保留动作与音轨
- Lip Sync：换风格后口型仍对准原声
- **启发**："保留原声"、"Subject Only 保背景"是用户预期中的默认项 → 我们已内置"保留原声"开关 + animate2 提示词换背景

### 可灵 Kling（动作控制 API）
- `kling-v3-motion-control`：参考图 + 参考视频 → 动作迁移；std/pro 两档；`character_orientation` 控制人物朝向跟随图或视频；最长 10s(图朝向)/30s(视频朝向)
- 国内大厂官方 API，可作为 Wan-Animate 之外的备选引擎接入
- 注意其限制：建议单人、一镜到底、动作平稳 —— 同样的选材建议在 UI 提示用户

### 阿里万相 `wan2.2-animate-mix` / WaveSpeed / fal
- 同一开源模型 Wan2.2-Animate 的多渠道托管：阿里云官方 + WaveSpeed + fal
- **已接入 WaveSpeed**（价格/直连/模型全：infinitetalk/animate/qwen-edit 一站齐）

### FaceFusion / ReActor（开源换脸）
- 纯换脸的轻量方案；只换脸不换身体/衣服 → 适合"保留原身材仅换脸"的补充节点，列入 roadmap

## 二、数字人口播产品

| 产品 | 定位 | 值得借鉴 |
|---|---|---|
| HeyGen | 国际化标杆，写实度第一梯队 | 模板化场景 + 多语言克隆 |
| 闪剪 | 国内高频口播/轻带货 | "文案→数字人→剪辑→分发"一条链路；AI 写文案 + 批量混剪；398/年 平民定价 |
| 蝉镜 | 电商直播数字人 | 平台推流集成（我们暂不需要直播） |
| 商汤如影/奇妙元 | 企业级高保真 | 质量上限参照 |
| 必火AI | 长期工作流型 | 强调"克隆-出片-剪辑-分发"闭环 —— 与我们"生成→审核→定时发布"闭环一致 |
| 剪映数字人 | 轻量试水 | 新手最低门槛参照 |

**结论**：我们的差异化 = 全自有素材库 + 半自动验收闭环 + 定时发布到抖音——
对标"必火/闪剪"的全链路，但产线自控、按 API 成本计费、可换引擎。

## 三、节点画布交互参照

| 产品 | 特点 | 借鉴点 |
|---|---|---|
| ComfyUI | 节点任意连线、全参数暴露 | 视觉语言（节点=方卡、连线=数据流、参数在节点内） |
| n8n / Dify | 工作流画布 + 节点配置面板 | 固定模板 + 节点内嵌表单，比 ComfyUI 更克制 |
| RunningHub | ComfyUI 在线版 | 模型/工作流市场概念 → 未来"管线模板库" |

**我们的取舍**：节点是**固定的功能卡**（输入→形象→引擎→后处理→审核），
连线示意数据流但不可乱接；参数藏在节点内表单，不暴露采样器/CFG 等底层旋钮。
画布引擎用 litegraph.js（ComfyUI 同款底层库），视觉一致、实现轻量。

## 四、竞品功能 → 我们的映射

| 竞品功能 | 我们的实现 |
|---|---|
| Viggle 整人替换 | Wan2.2-Animate replace（WaveSpeed API） |
| DomoAI Subject Only | replace 模式本身保留场景 |
| DomoAI 换背景 | animate-2 的 prompt 背景控制 |
| Viggle 模板库 | assets/sources 素材库 + 后续可接动作模板站 |
| HeyGen 照片数字人 | 形象照 + MiniMax 克隆声音 + InfiniteTalk 口播 |
| 闪剪 AI 文案+批量 | MPT 创作管线 + cron 定时批量 |
| 剪映级字幕/BGM | ffmpeg 后处理节点（字幕/响度/BGM） |
