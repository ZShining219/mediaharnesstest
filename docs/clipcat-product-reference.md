## 1. 产品定位

### 1.1 一句话

Clipcat 是面向 TikTok 电商的 **AI 视频生产 SaaS**：从"发现爆款"开始，拆解爆款结构，换成用户自己的商品与人物，调用多个顶级视频模型生成同款带货视频，再完成发布与数据复盘。

### 1.2 核心主张

- **"复刻爆款结构，而非照搬素材"**：拆解的是脚本节奏、镜头顺序、卖点表达，产出用用户自己的产品/角色重新生成。
- **"固定出镜人物"**：一次创建数字人/角色，系列视频形象一致，沉淀达人 IP。
- **"多模型自由切换"**：同一结构可跑 Seedance、Veo、Sora、Grok、Kling、Wan、MiniMax 等，按预算与风格选。
- **"零拍摄、零剪辑"**：选参考、传产品图、点生成，几分钟出片。

### 1.3 目标用户

| 人群 | 典型诉求 |
|---|---|
| 跨境电商卖家 | 看到同行爆款，快速做出自己产品的同款 |
| 投放/增长团队 | 大量素材做 A/B 测试，快速跑量 |
| 达人与 UGC 创作者 | 固定人设，把爆款结构做成系列内容 |
| 营销/代运营机构 | 多客户、多账号批量交付，质量可控 |
| 独立站/DTC 品牌 | 新品持续产出高质感带货短片 |
| 个人卖家 | 零剪辑经验，快速做出第一条视频 |

### 1.4 商业模式

- **算力订阅**：月付/年付，四档套餐（基础/创作/专家/企业），按算力消耗视频、图片、分析、榜单查看、竞对监控等。
- **免费入口**：注册送算力；视频分析 10 算力/次、链接解析 10 算力/次，先体验"拆解"再购买"生成"。
- **团队空间**：创作版以上支持子账号、共享算力池、并发队列。
- **Agent Skill/CLI**：把平台能力封装成 Agent 可调用的 CLI，按官网算力计费。

## 3. 落地页呈现方式

Clipcat 的落地页是典型的长页 SaaS 结构，在 1440px 宽下总高约 **11,362px**。它最大的特点是：**首屏不用宣传片/产品截图，而是把产品输入框本身当作 hero**。

### 3.1 逐屏结构

| # | 区块 | 内容 | 呈现手法 |
|---|---|---|---|
| 0 | 顶部促销条 | "重磅上线！前 1000 名用户专享优惠" | 蓝紫渐变、可关闭，制造紧迫感 |
| 1 | 吸顶导航 | 首页 / 产品 / 工具 / 模型 / 提示词 / Skill / 博客 / 定价 + 语言/主题/登录/注册 | 白 72% 透明 + 毛玻璃，注册按钮黑色胶囊 |

### 3.2 文案策略

- **标题即品类**：H1 直接写"TikTok 带货视频爆款复刻"，匹配搜索意图，而不是泛泛的"AI 视频生成"。
- **一句话差异化**：副标题"复刻的是爆款逻辑与创意，而不是简单照搬"在 hero、工作原理、对比表、FAQ 反复出现。
- **结果词而非技术词**：同款、爆款、出片、不判重、人物一致；模型只在"支持所有顶尖模型"处作为信任背书。
- **异议前置**：FAQ 主动处理合规、原创、判重、模型、剪辑门槛，甚至诚实回答"不能保证一定爆"。
- **人群自识别**：六类人群卡片让不同访客都能找到"这说的就是我"。

## 5. 核心功能模块

### 5.1 视频营销 Agent（主入口）

工作区首屏是一个 **Agent 对话框**，而不是传统功能菜单：

- 标题："电商视频营销 Agent / AI 员工来了，有什么可以帮你的？"
- 输入卡：图片附件（可粘贴截图/拖拽）、4,000 字 prompt、模型、参考视频、角色、分辨率/时长/语言/画幅、生成模式、算力消耗、发送按钮。
- 快捷动作：**选品 / 搜索爆款视频 / 生成带货视频 / 生成电商图 / 数据分析**。
- 下方：最近创建、爆款社区预览。

**交互范式**：用户不必先选功能模块，而是在一个框里描述需求，系统再决定调用哪个工具；同时保留参数 pills，让高级用户可控。

### 5.2 爆款复刻

**三步流程**：

1. 选一条爆款参考（链接 / 爆款社区 / 资产库 / 本地上传）。
2. 上传产品图，可选固定出镜人物、目标语言、视频模型。
3. 一键生成 9:16 竖屏 MP4，预览后下载，发布到 TikTok/Reels/Shorts。

**四种参考来源**：

| 来源 | 交互 |
|---|---|
| 粘贴 TikTok/抖音链接 | 异步解析出视频（轮询任务） |
| 爆款社区模板 | 浏览/筛选/收藏后一键复刻 |
| 我的资产库 | 从已上传视频选择 |
| 本地上传 | 拖拽/选文件 |

**四种复刻模式**（公开 JS 中确认）：

| key | 中文名 | 语义 |
|---|---|---|
| `similar` | 相似复刻 | 基于爆款整体结构，生成风格与脚本相似的全新视频 |
| `swap_person` | 人物替换 | 真人口播分镜保持人物特征，生成相似的数字人角色 |
| `keep_hook` | 保留钩子 | 保留原视频开场钩子/结构，替换产品与后续内容 |
| `swap_shots` | 分镜替换 | 保持分镜结构，替换部分分镜为相似画面，让成片看起来全新 |

四种模式共用的追加指令大意：完全复刻原视频脚本和画面；只把商品换成我的商品；有口播则结合我的商品改写；不要字幕；原视频有出镜人物则新视频也要有；时长控制在范围内。

### 5.3 爆款社区

爆款社区是 Clipcat 最厚的资产层，也是留存/复购的核心。

**六个 Tab**：

- AI 爆款提示词
- TikTok 榜单
- 搜索爆款
- 竞对监控
- 我的灵感库
- 精选案例

**AI 爆款提示词**：

- 定位文案："全球最大的 AI 带货视频提示库，这里全都是卖爆过的 AI 带货视频"。
- 搜索："支持语义检索：输入你想要搜索的视频画面、效果，即可检索到相关视频"。
- 筛选：国家（20+）、商品类目（30+）、时间维度（周榜/日榜/全部）、日期、排序（按 GMV）。
- 卡片：竖屏封面 + 排名角标 + GMV 标签。
- 详情字段（公开 JS 中确认）：`hook`、`hook_evidence`、`pain_point`、`visual_elements` 等结构化标签。
- 页面显示"共 3459 条 AI 爆款提示词"，是典型的程序化内容资产。
- 支持收藏、查看额度（免费/付费）、竞对监控账号数限制。

**TikTok 榜单**：按带货销量/GMV 排序的全球爆款榜单，支持国家/类目/时间筛选。

**搜索爆款**：关键词 + 地区 + 时间范围，按播放量排序，返回视频标题、播放量、达人、链接，并生成"爆款视频总结"（赛道趋势、钩子、互动率、复刻建议）。

**竞对监控**：按套餐限制监控账号数（基础版 3 个，企业版 70 个）。

**我的灵感库**：收藏的爆款/提示词，作为后续复刻的输入。

### 5.4 AI 工具

#### 视频分析

- 输入：TikTok/抖音链接，或本地上传 MP4（≤10MB）。
- 输出：逐个分镜的完整视频脚本——每个分镜包含：
  - 时间区间（如 0.0s–5.5s）
  - 镜头类型/画面描述（机位、走位、构图、道具、人物神态）
  - 口播稿（原声逐句转写，与画面对齐）
  - 视频类型标签（如"互动剧情演绎"）
- 计费：10 算力/次。
- 交互：左侧输入、右侧预览；支持"任务列表"查看历史分析。

#### 反推提示词

- 输入：带 video id 的 TikTok 链接。
- 输出：标准结构化提示词：
  - `Style`（风格）
  - `Environment`（环境）
  - `Camera`（镜头）
  - `Lighting`（光线）
  - `Character`（人物）
  - `Shots`（逐个分镜：时长、画面内容、主体动作）
- 用途：复制整段丢进主流 AI 视频模型，复刻爆款拍法。
- 计费：按次/算力（页面未标价，工具页归入"生成带货视频"类）。

#### 画质提升

- 一键超分，让模糊素材变高清。
- 归入"生成带货视频"工具组。

#### 其他工具矩阵

| 分组 | 工具 |
|---|---|
| 发现爆款 | 采集爆款视频、视频分析、TikTok 蓝海爆品发现、下载 TikTok 视频 |
| 生成带货视频 | 爆款带货提示词生成器、视频画质提升、视频转提示词 |
| 生成电商图 | 图片翻译、商品套图、场景图、卖点图 |
| 数据分析 | 提取创作者视频 |

**采集爆款视频**：输入关键词 + 目标地区 + 时间范围（最近 1 天/一周/一月），按播放量排序输出榜单，附原视频链接、达人信息，并生成"爆款视频总结"。

**商品套图**：上传一张产品图 + 卖点（选填）+ 文案语言，一次生成 7 张成套电商图：白底主图、卖点信息图、四宫格多视角、使用场景图、细节特写四宫格；适配 TikTok/Amazon 规范；底层用 GPT image、香蕉 Pro 等图片模型。

**场景图 / 卖点图 / 图片翻译**：把商品融入真实场景、自动排版卖点、翻译商品图文案，适配多国市场。

**提取创作者视频**：批量提取达人全部视频，建立素材库。

### 5.5 数字人视频

- 定位："用 AI 生成或上传一张照片，创建和真人一样、完全看不出的数字人；设置一次，固定出镜。"
- 三步：生成或上传照片 → 保存出镜形象 → 输入脚本/想法 + 选模型 → 一键生成。
- 核心卖点：真人质感、固定出镜、全模型兼容、无需真人、随时量产。
- 与常见的"每次上传照片"式数字人不同，它强调 **一次创建、跨视频固定复用**。

### 5.6 视频生成器（TikTok 视频生成）

- 定位："找爆款 · 一键复刻 · 生成同款"。
- 三条入口：带货销量榜找爆款 → 一键复刻；粘贴链接生成同款；上传产品图 + 提示词直接生成。
- 支持固定人物、多模型、9:16 竖屏。
- 与"爆款复刻"页的差异：更强调"从找爆款到出片"的一站式，而爆款复刻页更强调"结构复刻"的方法论。

### 5.7 视频发布

- 状态筛选：全部 / 等待定时发布 / 发布中 / 已完成 / 发布失败。
- 新建发布：选择内容、账号、发布类型（立即/定时）。
- 表格字段：内容（创建时间）、账号、发布类型、状态、数据、操作。
- 平台账号：TikTok 账号连接/断开。

### 5.8 数据分析

- 会员功能；升级后可解锁账号全部作品的经营数据。
- 三个视角：
  - 按账号：跟踪所有 TikTok 账号关键指标。
  - 按作品：视频排行，好内容直接"复刻裂变"。
  - 汇总和比较：汇总数据、比较作品表现。
- KPI 卡：总播放量、本周点赞、本周评论、本周分享、本周互动率、粉丝总数、账号总获赞、本周发布、本周观看量。
- 图表：播放与涨粉走势、互动走势。
- 视频排行表：视频、发布时间、播放、点赞、评论、分享、分享率、互动率、操作。
- "复刻裂变"：对站外视频，提示"需要先解析视频链接，将消耗 10 算力"；对已发布视频直接复刻。
- 未升级时展示示例数据，并明确标注"以下均为示例数据"。

### 5.9 我的资产

- Tab：收藏 / 批量下载 / 项目空间 / 历史上传。
- 项目空间：按项目组织生成内容；空状态"暂无项目"。
- 支持批量下载。

## 9. 关键交互机制

### 9.1 Agent-first 输入

- 一个输入框承载"描述需求 + 附件 + 参数 + 模型 + 算力"。
- 快捷动作把常见意图（选品/搜索爆款/生成视频/生成电商图/数据分析）变成 chips。
- 生成模式在 UI 上表现为"一键成片 / 对话生成"；代码中区分 `fast`、`guide`、`raw` 等模式。

### 9.2 跨页预填（一键复刻）

- 公开 JS 中有 `clipcat:replicate-prefill` localStorage 键，TTL 约 5 分钟。
- 用户在灵感库/数据分析点"复刻"后，把参考视频、产品图、语言、模型、分辨率、时长、画幅、prompt 等写入 localStorage；生成器读取后自动填表。
- 这是"从发现到生成"最短路径的实现方式。

### 9.3 异步任务与轮询

- 链接解析：POST 创建任务 → 每 3 秒轮询 `?taskId=` → 15 分钟超时。
- 生成任务：工作区每 15 秒刷新最近项目；未完成任务持续轮询。
- 任务状态：排队/运行/完成/失败；失败保留 provider task id，支持找回。

### 9.4 额度与配额

- 算力余额、套餐到期、冻结算力、每日/每月配额。
- 灵感库查看、搜索、竞对监控都有独立额度，按套餐分层。
- 生成失败仅在系统问题下退还算力；效果问题不退，降低争议。

## 11. 产品优点与边界（对标视角）

### 11.1 优点

1. **定位极清晰**：一句话说清"爆款复刻"，不是泛 AI 视频工具。
2. **落地页把产品当 hero**：用户第一眼就能操作，不需要看视频/截图。
3. **真实案例墙**：用真实成片做社会证明，比 stock 素材有效。
4. **爆款资产层厚**：3,459+ 提示词、榜单、竞对、语义搜索、收藏，形成内容飞轮。
5. **模型路由成熟**：能力/价格/约束注册表，前端动态渲染，用户按预算选。
6. **算力体系完整**：生成、分析、解析、榜单、竞对统一计费，套餐分层清晰。
7. **Agent 分发**：Skill/CLI 把能力嵌进用户已有的 Agent 工作流，是差异化渠道。
8. **转化路径短**：从灵感库/数据页一键复刻，localStorage 预填上下文。

### 11.2 边界与风险

1. **无人工审核闸门**：生成即结果，质量/合规依赖用户自查。
2. **单次生成 vs 多镜叙事**：其核心仍是"参考视频 + 产品图"的单次生成，对复杂多镜脚本的控制有限。
3. **GMV 数据依赖**：榜单/排序依赖 TikTok Shop 生态数据，外部难以复制。
4. **合规风险**：复刻结构/人物替换涉及版权、肖像权、平台判重；其话术降低但未消除风险。
5. **功能广度大**：14+ 工具容易分散，单点深度可能不足。
6. **算力定价复杂**：模型/分辨率/时长/补贴档位多，用户理解成本高。
7. **程序化 SEO 内容质量参差**：大量模板页可能稀释品牌。
8. **闭源 SaaS**：不可私有化、不可换底层引擎、数据在云端。

### 11.3 作为对标产品的可借鉴结论

- 产品叙事：用"结果词 + 一句话差异化 + 对比表"定义品类。
- 入口形态：把输入框做成 hero，参数用 pills，成本即时可见。
- 资产层：爆款库/提示词库/收藏/竞对是留存与复购的核心。
- 能力层：模型注册表 + 算力计费 + 异步任务 + 跨页预填是基础设施。
- 分发层：Agent Skill/CLI 是把能力嵌入用户工作流的有效方式。
- 边界：不要在没有数据源时承诺 GMV；不要把"复刻结构"说成"绝不判重"；不要让工具广度牺牲主链路深度。
